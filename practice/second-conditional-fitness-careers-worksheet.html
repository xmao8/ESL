Second Conditional — Fitness & Health Careers

How it works

The second conditional talks about imaginary or unlikely situations now. Form it with If + past simple, would + base verb: If I had more time, I would walk every day, If she exercised daily, she would feel stronger. Use were for all subjects in the if part (If I were a nurse …).

Examples: If he ate less fast food, he would lose weight.  ·  If we lived near a park, we would run there.

Fill in the Blanks (15)

✏️ Now use it: Write 3 sentences about your own health or dream job using the second conditional — start each one with If I …. Read them to a partner.
